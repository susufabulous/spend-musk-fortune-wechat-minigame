# 花光世界首富 Musk 的财富 · 微信小游戏

一款休闲模拟类微信小游戏：以马斯克 4000 亿美元身家为起点，旗下产业每秒自动进账，你要做的就是——把钱花光。
微信小游戏名称--穿成老马后我忘本了

## 玩法

- **初始资金**：$400,000,000,000（$400B）
- **被动进账**：旗下产业每秒自动产生收益，买的产业越多，进账越快
- **购买资产**：50 件商品，分 8 大类
  - 交通（特斯拉、劳斯莱斯、房车…）
  - 空中（直升机、湾流飞机、波音 747、龙飞船…）
  - 水上（豪华游艇、潜水艇、帆船…）
  - 房产（半山别墅、顶层公寓、欧洲城堡…）
  - 土地（私人岛屿、地标摩天楼、私人机场…）
  - 收藏（梵高真迹、粉钻、百达翡丽…）
  - 产业（特斯拉股份、SpaceX 股份、NBA 球队…买了涨进账）
  - 神操作（给粉丝发钱、刷纪念碑、包下时代广场…支持自定义添加）
- **出售变现**：已购资产可原价卖回
- **结算评级**：游戏结束后根据剩余资金与耗时评定 SSS ~ E 共 8 个等级，展示购买明细清单，可分享给好友晒战绩

## 技术栈

- 微信小游戏原生 Canvas API（无框架、无构建）
- `game.js` 入口 + `js/main.js` 主循环 + `js/databus.js` 数据与逻辑 + `js/render.js` 渲染
- 触摸事件 + `wx.showKeyboard` 自定义商品输入 + `wx.shareAppMessage` 分享

## 目录结构

```
├── images/                  # 商品图片（1.jpg ~ 50.jpg，按 databus.js 数组顺序）
│   └── elon.jpg             # 马斯克头像
├── js/
│   ├── databus.js           # 50 件商品数据、状态机、buy/sell 逻辑
│   ├── main.js              # 主循环、触摸事件、键盘输入、分享
│   └── render.js            # Canvas 绘制（顶部信息栏 + 侧边分类 + 两列卡片 + 结算页）
├── game.js                  # 小游戏入口
├── game.json                # 运行时配置
├── project.config.json      # 项目配置
└── project.private.config.json  # 本地个人配置（不入 git）
```

## 本地运行

1. 下载 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 导入本项目目录
3. AppID 选择"测试号"或填你自己的小游戏 AppID
4. 点编译即可在模拟器运行

## 自定义商品图片

商品图片命名规则：`images/1.jpg` ~ `images/50.jpg`，对应 `js/databus.js` 中 `BUILTIN_ASSETS` 数组顺序。没放图的商品自动用 emoji 兜底。
